# 🤝 Test Pair Achievement

A playground repository created to test **co-authored commits**, pull request merges, and unlock the GitHub **[Pair Extraordinaire](https://github.com/badges)** achievement badge.

---

### 🎯 Purpose
To earn the **Pair Extraordinaire** badge on GitHub, a commit must:
1. Include valid `Co-authored-by` Git trailer syntax in the commit message.
2. Link to a collaborator's verified GitHub email address.
3. Be part of a Pull Request merged into the default (`main`) branch.

### 📝 Commit Trailer Example
```text
feat: add collaborative test commit

Co-authored-by: CollaboratorName <collaborator_email@example.com>
```
